## ✨ Sobre o Projeto

Este é o FrontEnd do meu portfólio pessoal, uma aplicação web onde apresento meus projetos, experiências profissionais, habilidades e informações de contato.  
A interface consome dados da minha [API Portfólio](https://github.com/LeoBP1987/api-portifolio), permitindo que as informações estejam sempre atualizadas e de fácil gerenciamento.

O objetivo deste projeto é centralizar e destacar minha trajetória profissional, tornando simples para recrutadores, parceiros ou colegas conhecerem meu trabalho.

## 🔌 Integração com BackEnd

Este FrontEnd foi desenvolvido para consumir dados diretamente da [API Portfólio](https://github.com/LeoBP1987/api-portifolio).  
Dessa forma, consigo atualizar as informações do meu portfólio de maneira centralizada, sem precisar modificar o código do FrontEnd.
